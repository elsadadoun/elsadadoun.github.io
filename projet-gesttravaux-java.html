☕ GestTravaux Pro – Version Java

Application Desktop avec JavaFX

Technologie principale JavaFX
Backend Spring Boot
Base de données MySQL
Type Application Desktop

Dans la version Java, l'application est principalement réservée au gestionnaire qui gère les chantiers, les biens, les propriétaires, inspecteurs, entrepreneurs, prestations, catégories et les devis. Elle accède directement à la même base de données MySQL que l'application Symfony, garantissant la cohérence en temps réel.

Il y a aussi une partie administration pour gérer les comptes utilisateurs (inspecteurs, entrepreneurs) et ajouter des prestations, des biens et catégories.

🎯 Objectifs du projet

  • Digitaliser et moderniser le processus de gestion des travaux immobiliers
  • Améliorer la traçabilité des échanges et décisions
  • Centraliser l'information dans une base de données unique partagée
  • Optimiser la gestion des délais et budgets

Fonctionnalités Principales

✔️

Gestion des Chantiers

Création, suivi et clôture des chantiers avec gestion des échéances et des ressources

💵

Système de Devis

Génération automatique de devis détaillés avec calcul des coûts et des marges

⚖️

Comparateur de Devis

Comparaison des fournisseurs et des matériaux selon plusieurs critères (prix, qualité, délai)

📈

Tableaux de Bord

Visualisation en temps réel des indicateurs clés de performance (KPI)

📱

Interface Responsive

Application web adaptée à tous les écrans (ordinateur, tablette, smartphone)

🔐

Système d'authentification

Authentification sécurisée avec gestion des rôles (gestionnaire, inspecteur, entrepreneur, propriétaire)

Présentation du projet

C'est une application de gestion de travaux immobiliers, sur laquelle nous avons travaillé en équipe. L'objectif du projet est de permettre le suivi de différents éléments liés à l'activité : les biens, les chantiers, les inspecteurs, ainsi que les devis.

Ce projet est intéressant, parce qu'il existe en deux versions : une version desktop en Java / JavaFX et une version web en Symfony.
